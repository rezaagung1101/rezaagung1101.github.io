Xporter Camera

Case study →

Personal project · Solo · 2026

Built and tested on a real Fujifilm X-T3

Android app that copies photos from a Fujifilm camera to the phone over USB or Wi-Fi, then shares them with their film simulation recipe.

  • Implemented PTP over USB and Fujifilm's PTP/IP Wi-Fi protocol in Kotlin, researched from open-source documentation and verified on the camera.
  • Safe by design: every camera command passes a read-only allowlist, and the only writes are session settings that are restored when the session ends.
  • Multi-module Clean Architecture with convention plugins, and CI that runs formatting, lint, and unit tests on every pull request.
Kotlin Jetpack Compose Coroutines/Flow Hilt Room Multi-module PTP/IP GitHub Actions

Qurbanku

Case study → GitHub Demo

Undergraduate thesis · Solo project · 2024

Android app that lets a mosque's qurbani committee and its congregation organize and jointly fund qurbani animals, built for Masjid Al Huda, Malang.

  • Two role-based flows. Committee members list animals and approve or reject payments. Congregants find a mosque, join a shared animal, and upload proof of transfer.
  • In-app camera built with CameraX for animal photos and payment proofs, stored in Firebase Storage.
  • Mosque discovery and location picking with Google Maps SDK and Fused Location.
Kotlin MVVM LiveData Firebase Auth Firestore CameraX Google Maps SDK Navigation
